# Claude Code as target platform, not the agent-skills packaging spec

This repo's skills target Claude Code's symlink install, not the official agent-skills packaging spec: frontmatter keeps the non-spec keys the suite's design depends on — `disable-model-invocation` for the invocation axis (ADR-0015) and `requires:` for declared dependencies (ADR-0016) — which the official validator's closed six-key set (`name, description, license, allowed-tools, metadata, compatibility`) would reject. Nesting our keys under the spec's open `metadata:` field was rejected: Claude Code only honors `disable-model-invocation` at top level, and burying `requires:` would hide the dependency contract from `install.sh` and lint's plain-frontmatter parsing. `lint-skills.sh` adopts only the spec limits that are platform-true in Claude Code (`name` ≤ 64 chars, no angle brackets in `description`).
