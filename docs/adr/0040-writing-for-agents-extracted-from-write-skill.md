# writing-for-agents extracted from write-skill

The agent-prose conventions (information hierarchy, pruning, writing style, the leading-word/context-pointer vocabulary) lived inside the user-invoked `write-skill`, where the model could never reach them while editing the other documents they govern — a `CLAUDE.md`, a reference file, agent-read `DOMAIN.md` or ADR prose. We extracted them into a model-invoked behavior, `writing-for-agents`, which `write-skill` declares via `requires:` while keeping its name, flag, and skill-package orchestration (classification, structure, description, testing) — the same orchestrator/behavior split as `grill-me`/`grilling`. Upstream mattpocock rescoped his skill the same way, 2026-08. The name is kept on merit — the audience-in-the-name is the load-bearing contrast with the human-audience plain-English skill. Rejected: renaming `write-skill` and flipping the whole skill model-invoked (drags authoring orchestration into every model invocation), and a jurisdiction note inside the user-invoked skill (a rule at an address the model can never reach).
