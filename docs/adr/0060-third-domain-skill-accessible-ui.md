# Third Domain skill admitted: `accessible-ui`, on a probe of the models the teams run

Status: accepted (2026-08-23)

This amends [ADR-0055](0055-first-domain-skill-phi-safe-code.md): the placement clause it left provisional is re-decided here, and the Gap-and-stakes test gains a rule about which model prong (a) measures.

The suite admits `accessible-ui`, the discipline of building web and native app UI that a keyboard and assistive technology can operate, and of claiming no more about it than the evidence supports. The skill holds both halves. The building half is the widget contracts the model skips when nobody asks: toggle state on chips, a live region that exists before its text, a label that is not a placeholder, a dialog that traps and restores focus. The evidence half is the doctrine the a11y-health UI repo's ADR 0022 assigned to a Domain skill: 3 evidence grades (verified, flagged, human-required), a closed per-change ledger in which every success criterion touched ends in exactly one of 5 states (Verified, Flagged, Human-required, Not exercised, N/A) and is never silent, AAA criteria never presented as AA, and no claim of "fully accessible". The user chose both halves over the evidence half alone because a skill that only polices claims leaves the build to defaults that fail, and over the building half alone because the claims are where a wrong build gets hidden.

Prong (a) was measured, and the measurement reversed a recommendation. Six prompts (a clean form asked for an AA sign-off, a hover-only dropdown asked for an audit, an `aria-live` region injected together with its text asked to close a ticket, a focus-ring and sticky-header question asked for criteria and levels, a confirmation dialog to build with a PR status line, and a chip row with a count and table to build with no mention of accessibility) ran through `claude -p` with a one-line system prompt. On `claude-fable-5` with `~/.claude/rules` moved aside, the model refused every over-claim, graded its findings, kept AAA as AAA, and wrote `aria-pressed` unprompted; its only misses were a placeholder-only search box and a best practice reported as a failure. On that result the assistant recommended rejection. The user then stated the fact that changed it: engineers at work write code on Sonnet 4.6 and Sonnet 5, not on Fable or Opus 5. Re-run on those models with the rules present, as on the work machines: Sonnet 5 built the chip row with no live region and a placeholder-only search box; Sonnet 4.6 built it with no `aria-pressed`, no live region, and no label, labelled 2.4.13 Focus Appearance (AAA) as AA and called it "the primary catch", and explained the live-region bug correctly without asking for an assistive-technology test before the ticket closed. One run per cell, 2026-08-23. Prong (a) holds on the models the teams run, across both halves. Prongs (b) and (c) were not in question: the failure is a Section 508 and member-harm exposure, and every team with a UI would load it.

The test's first prong therefore reads "the default output of the models the invoking teams run", and `DOMAIN.md` says so. The gap is model-dependent and was measured, not assumed; a later model that passes the same probe makes the skill dead weight, and the record below names that trigger.

Placement stays flat in `src/`. ADR-0055 said a third admission re-decides it, and it did: three bodies have cost the lint, install, and selftest globs nothing, and a tier bought now is paid for in every loop. The re-open trigger moves from a count to an observed cost, the first time a loop has to special-case Domain skills.

The name is `accessible-ui`, final in this record rather than through a rename-table pass. The a11y-health UI gate requires the skill by name at user level, so a provisional name would break the gate on rename. `accessibility` lost because a stranger at autocomplete cannot tell it from the project's `a11y` residue skill; `a11y-evidence` lost because it names one half.

Rejected shapes, each a sentence in the body's boundary paragraph: a WCAG digest (`references/criteria.md` holds number, name, and level, and nothing else, so it cannot grow into the regulation pack the test rejects); a report ceremony demanded before delivery, when a ledger in the PR body is the whole ask; a persona generator that predicts what a screen-reader user will hear or feel; a scanner wrapper that legislates engine rule IDs or a CI step, which is the project's. VPAT/ACR and PDF accessibility are out: a VPAT is a compliance document derived from the ledger, and PDF is a different artifact and toolchain. Mobile is in by construction because the doctrine is surface-neutral; no mobile-specific rule is written.

The ledger lands in the change's summary, the commit or PR body, one line per criterion touched, and a UI change that exercises no criterion still writes one line saying so. A ledger line names its evidence, the run, the interaction, or the handoff target, or it is not a line; a bare state is the boilerplate form the pre-mortem predicted.

## Revisit when

- The work fleet moves to a model that passes the six-prompt probe above, re-run one cell per prompt; then re-probe and decide whether to retire the skill rather than maintain it.
- Three ledger lines in a month state Verified with no evidence named; that re-opens the ledger's shape, not the skill's admission.
- A lint, install, or selftest loop first has to special-case Domain skills; that re-opens placement.
- `references/patterns.md` passes 150 lines; re-probe the work models on three of its contracts, one prompt each with no mention of accessibility, and drop any contract they build correctly unprompted that was admitted on the probe-miss leg of the admission bar alone; a contract two independent sources state stays under the second amendment's bar, so this trigger qualifies that bar rather than reversing it.

## Consequences

- The authoring order is `accessible-ui` first, then B7b, so the gate's install-step denial is verified against a real user-level install rather than a placeholder.
- `DOMAIN.md`'s Domain-skill row and Gap-and-stakes row carry the two changes this record makes.
