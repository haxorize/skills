# `CLAUDE.md` admits only triggers and contracts; everything else is one pointer away

> **Amended by [ADR-0077](0077-tightening-round-one-house-style.md):** the "before it knows to look" admission test now governs `global/rules/` as well as `CLAUDE.md`.

`CLAUDE.md` had grown to 2,282 words over 49 commits (`wc -w CLAUDE.md` and `git log --oneline --follow -- CLAUDE.md | wc -l`, 2026-08-30), and it loaded on every session and every subagent. Two sections carried 79% of it: a 555-word list of ported-skill upstreams and a 1,240-word account of the lint gates. Most of both restated something the environment already answered. The swept points are the amendment ledger in [ADR-0034](0034-branch-mining-lineage-or-dormant-main.md), each script's roster and exit codes are its own `--help`, and the invocation axis is `write-skill`'s. What had no other home was small: the mapping from a local skill name to its upstream name, the three gate rules that bind every script rather than one, and the cross-quote exception to the commit order.

We decided that a sentence stays in `CLAUDE.md` only if an agent needs it *before it knows to look* — a trigger ("before materially editing any skill or scanner rule, check `docs/lineage.md`") or a contract another tool reads from this file by shape (`Landing:`, `## Review lenses`). Everything else is judged by `writing-for-agents`' cache test, which decides whether the cut material needs a new home or already has one. Nick chose this over the cache test alone, which would have kept the whole lineage table because the name mapping is not findable elsewhere, and over the placement test alone, which would have cut "run the linter before committing" as findable.

The cut material lands in four places. `docs/lineage.md` holds one row per skill or scanner rule with a lineage other than local original — upstream repo, upstream name, licence, admitting ADR, and whether an edit diffs first — and closes with the sentence that every skill not listed is a local original; the swept points stay in ADR-0034, joined to the table by the upstream name. `scripts/README.md` holds the three cross-script rules — which selftest runs after touching what, that a new or edited check lands with a fixture instance and a mutation that reds its selftest in both directions, and the review-fix-commit-push order — and no roster, because `post-merge` derives the gate list and `--help` prints each check list. The cross-quote exception to the commit order moves into `ship`, which already says the project states its own order in `CLAUDE.md`. The invocation-axis section is deleted outright: `write-skill` owns it and `check_invocation_axis` enforces the pairing.

Two drifts are forbidden, because nothing else would stop them. The disclosed files must not become the next dumping ground, so each opens with its own one-line keep test — a lineage row, or a rule that binds more than one gate — and anything else goes to an ADR. And a `CLAUDE.md` pointer must not drift into a summary good enough that the agent never opens the file, so every pointer names the trigger and the file and never what the file says. The lineage trigger fires on *every* skill edit, not on ported ones: an agent opening `grilling` cannot know it is ported until the table says so, and a trigger conditional on the fact it exists to reveal never fires.

Tooling carries what prose could not. A `check_claude_md_bytes` WARN at 6,000 bytes in `lint-skills.sh` — a round bound roughly 2.4 times the 2,471-byte post-cut file (`wc -c CLAUDE.md`, 2026-08-30) and just over a third of the 16,672-byte pre-cut one, on the `check_reattach_bytes` precedent — with a fixture instance and a selftest mutation both ways; a WARN rather than a FAIL because one growth is the weak end of observed evidence. A `pre-commit` git hook that runs `lint-skills.sh` when a staged path is under `src/`, `global/`, `.claude/skills/`, `scripts/`, or is `README.md`, `DOMAIN.md`, or `CLAUDE.md`, and `lint-adrs.sh` when one is under `docs/adr/`, so "run the linter before committing" leaves the prose; the two linters take 10.5 s and 2.5 s (`/usr/bin/time -p`, 2026-08-30) and neither calls `mktemp`, so the hook runs on the work machine too. The same hook maps a staged gate to its proof — a staged `scripts/<x>.sh` runs its `<x>-selftest.sh`, a staged git hook runs its own selftest, and a staged `selftest-lib.sh` runs them all — so the commit that edits a check re-runs the red that guards it. And because a file cut to pointers is only as good as its pointers, `lint-skills.sh` checks that every relative link target in the root `CLAUDE.md` exists, so the hook refuses a commit that leaves one dangling. The hook extends the opt-in [ADR-0049](0049-opt-in-post-merge-hook-auto-runs-install.md) made and [ADR-0067](0067-commit-msg-hook-checks-shape-not-register.md) widened — one `setup-hooks.sh` run now enables three git hooks, and this one blocks — and ADR-0049's amendment of this date is the trust record for it. And `check_script_selftest`'s walk widened to `scripts/git-hooks/`, so the new hook's selftest is demanded rather than conventional. Every file under `scripts/` and `scripts/git-hooks/` — the `*.sh` gates and selftests, the extensionless git hooks, and the sourced `selftest-lib.sh`, which has no shebang and carries it at line 1 — gains one header line pointing at `scripts/README.md` (line 2 after a shebang, line 1 without one; `lint-skills.sh`'s `check_conventions_pointer` fails a file that lacks it), because the agent that opens the script instead of `CLAUDE.md` still has to meet the rules.

## Considered Options

- **A lineage table inside ADR-0034** — one home for lineage. Rejected: the record's amendments already supersede each other 5 times over, so a reader finds the live ledger by date; current truth does not belong in a record.
- **An `upstream:` frontmatter line on each ported `SKILL.md`, lint-checked** — the fact in the file the agent edits. Rejected for now: around 30 edits and a lint rule, and a field that travels into every project the skills are symlinked into, against no evidence yet that the trigger is missed.
- **Keep the three gate rules in `CLAUDE.md`, condensed** — defensible, but about 300 words loaded on every session, including the many that never touch a script.
- **A FAIL on size, or no check** — a FAIL over-escalates on one incident; no check is what stood for 49 commits.

## Deferred

- A lint check that every `src/*` directory has a row in `docs/lineage.md`, so "not listed" can never mean "forgotten" — reopened the first time a ported skill is found missing from the table; settled by a `lint-skills.sh` check with its fixture pair.

Revisit when: a commit touches `src/<skill>/` for a skill with a Ported row in `docs/lineage.md` in a session whose transcript holds no read of that file — or, the same miss seen late, a diff of a ported skill's upstream finds a change the local edit did not see. Either is the one-line trigger lost to the habit of opening the skill and editing. The first answer is already built, in this same tree: `pre-commit` prints a lineage notice — one stderr line pointing at `docs/lineage.md` — for a staged `src/<skill>/` path whose skill has a row there, a WARN that never blocks, chosen over the frontmatter key because the repo already pays the travelling-key cost twice (`requires:`, `disable-model-invocation`; [ADR-0030](0030-claude-code-over-agent-skills-spec.md)) and the hook costs zero edits to 30 skills. The frontmatter option above is the answer only for a miss that survives the notice.

## Consequences

- `CLAUDE.md` lands near 2 KB; the always-loaded budget per session drops from about 5,600 words to about 3,600, of which the 6 rules files are 2,945.
- Every consumer that named a `CLAUDE.md` section is repointed in the same change — twelve sites, the second seven found by the review of the fold after the first five had been called exhaustive: `lint-skills.sh`'s header and its two router FAIL strings; `security-selftest.sh`'s "the Linting rule"; [ADR-0072](0072-shared-trigger-phrase-check-and-never-ran-is-not-clean.md)'s line; a dated amendment to ADR-0034 saying the trigger resolves through `docs/lineage.md`; `lint-skills.sh`'s two "one selftest per hook" quotations, its single-line-description citation, and its "router line" citation; `lint-skills-selftest.sh`'s "its two definition sites agree" quotation; `DOMAIN.md`'s **Mutation table** row, which cited § Linting for the fixture-and-mutation rule; and `mine-skills`' "ported-skill list in `CLAUDE.md`", which now names `docs/lineage.md`.
- The MIT and Apache attributions that `CLAUDE.md` said "belong here" now live in the table's licence column; the mirror sync carries `docs/`, so the work machine keeps them.
- `DOMAIN.md` gained **Lineage**, **Swept point**, and **Lineage table**, and a Relationships line for the join.
