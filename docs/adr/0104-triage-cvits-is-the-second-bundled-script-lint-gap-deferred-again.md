# triage-cvits is the second bundled script, and the `src/*/scripts/` lint gap closes with it

`triage-cvits` is the second skill to bundle a deterministic script under `src/<skill>/scripts/`, after `inventory-cvits` ([ADR-0103](0103-bundle-deterministic-skill-logic-as-a-tested-script.md)). It ships `scripts/classify-cvit-findings.py` with `classify-cvit-findings-selftest.sh` and a `classify-cvit-findings-fixtures/` directory beside it. A second bundle was the trigger for closing the gap that left these scripts outside the lint and the commit gate, and this change closes it. `lint-skills.sh` puts `src/*/scripts/*.sh` and `src/*/scripts/*.py` on the same script-and-selftest pairing contract as `scripts/` (its `graded_scripts` list). The `pre-commit` hook queues the paired selftest when a bundled script or a file under its `-fixtures/` directory is staged, and queues every `src/*/scripts/` selftest when a `scripts/*-lib.sh` is staged.

The first draft of this record deferred the closure again. It weighed the roster work, a new tree and a non-`.sh` extension, against two consumers whose selftests were green and run by hand. The review of the work-machine import reversed that in the same change, for two reasons. ADR-0075's 2026-09-01 walk showed that the closure is a few lines. The deferral's own reopening trigger, a selftest found rotted, could not fire while nothing ran the selftests. `scripts/mutation-sweep.sh` still does not reach these scripts, and ADR-0103 states its reach.

The three classifier questions that review raised were settled in `classify-cvit-findings.py`, not on a measurement, per the repo's `Defect policy: fix, don't file`. A finding with no PURL outside an app path is Bucket A **unconfirmed**, so a no-PURL application component is flagged rather than asserted safe. An at-or-above verdict is asserted only when the major key and the (major, minor) key agree; otherwise the finding is F unconfirmed, which keeps a minor-keyed Fix Status from clearing an install below its own line. A nested-path finding is judged by its own row's version, and `triage-cvits` step 3 spells the `npm ls` reduction.

The classifier's other design decisions (the three-tier cascade, the two-tree differential, the bucket definitions) live in `src/triage-cvits/SKILL.md` and `src/triage-cvits/references/buckets.md`, not here.
