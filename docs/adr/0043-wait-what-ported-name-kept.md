# wait-what ported from mattpocock's wait-what, name kept

The suite had no corrective for the live conversation when an explanation stops landing — `/writing-for-humans` edits artifacts, and "be concise" style prompts make a model clip words and lose the listener further. mattpocock's `wait-what` (2026-08-08 mining round) is a deliberately tiny user-invoked skill whose design insight is *name the listener's state, not the output*: "wait, you lost me" produces a re-pitch with the missing context, where "be brief" produces telegrams. We ported it nearly verbatim, substituting only where the upstream leaned on external context: the bare "ASD-STE100" name-drop (which leaned on the model's prior about an external standard) becomes a `requires:` on `writing-for-humans`, whose plain descriptive register is defined locally, and the `CONTEXT.md` vocabulary binding becomes `DOMAIN.md`, this repo's equivalent, with the upstream's graceful-degradation clause kept. We considered renaming it `lost-me` for symmetry with the `-me` family and rejected that: the family is imperative grammar ("grill me", "teach me") and "lost me" is a declarative fragment, while "wait" is the upstream's load-bearing leading word — the name is the mechanism, so it stays.

## Amendments
