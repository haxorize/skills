# Mine transcripts as a source, stamp every generated report, and prove a gate can go red

The 2026-08-29 `/mine-skills` round read 31 user-named sources and delta-mined the 91 repos under `~/code/lib` that had moved since the 2026-08-27 baseline. It wrote 347 ledger rows — 10 ADOPT, 66 ADAPT, 67 PARK, 3 NOTE, 201 REJECT (`~/code/lib/_rounds/2026-08-29/ledger.md`) — placed every ADOPT and ADAPT in one of 20 batches in `reconcile.md`, and proposed no new skill. The suite stays at 57. The round's 13 grill questions plus 3 the grill grew were put to Nick on 2026-08-29 and this record holds the answers; the round's batches are the work those answers shape, and each batch amends this record as it lands, the way [ADR-0073](0073-team-fit-mining-round.md) accumulated the previous round's.

The decision that names the round: **the round's best-evidenced finding came from the user's own transcripts, not from any source repo**, and the round had no place to put it. `DET-2` — a session's deferrals never reaching the durable record — appeared 9 times across 9 distinct sessions in 4 days (`friction-evidence.md`, rows `FE-F18`–`FE-F26`) and had no ledger row, because `mine-skills` reads transcripts only to grade friction on rows the repos produced. Three rounds of public skill repos have produced folds and no new skill; one read of the transcripts produced this on its first pass. So the next round adds the transcript corpus as a named source class with a report of its own, judged under the Team-fit test like any repo, and keeps the repo read unchanged — dropping the new-skill question from repo reads was rejected because the read contract already asks fold-or-new on every read, and dropping it saves nothing while blinding the round to the one repo that does carry a skill.

This record clears the ADR gate on all three criteria. **Hard to reverse:** the folds carry no markers, so this record and the round directory are the only map back to them; the mutation rule and the `Measured-tree:` line are conventions every later gate and report copies, and withdrawing either means finding every copy. **Surprising without context:** a reader who finds a mining report stamped with a work-tree hash, or `mine-skills` reading the user's sessions as a source, will ask why. **A real trade-off:** every question below had an alternative a rational team could have taken, and the *Considered Options* section holds the ones that lost, including 4 where the grill document's own recommendation lost.

## Method changes, for the next round

Three, each answering a defect this round measured in its own instrument.

- **Transcripts are a source class.** `mine-skills` gains the class beside the repo read, with the same read contract: licence written "n/a; own corpus", friction observed by construction. The must-NOT is written with it: a round states its repo-row to transcript-row ratio, so a round that has become a review of one user's sessions shows it in one number. `DET-2` itself takes no retroactive row; it lands as prose under the batch decisions below.
- **The enumerator reports its own blind spot.** `enum.sh` could not read `description: >-` or `|-`, so 478 + 3 of 18,991 entries across 396 sources printed the marker as their description and were invisible to every description-driven shortlist in every prior round (`awk -F'\t' '$4==">-"' full-enum.tsv | wc -l` → 478, now 0 after the fix at `enum.sh:11`). The fix is the count: each run prints, on stderr, how many entries it could not parse. A prose clause requiring every round script to find a known-present case was rejected as already covered — `global/rules/evidence.md` states that rule for every search, and `mine-skills` applies "already covered is a placement fix" to everything else.
- **The briefing carries two friction vocabularies and a pointer to the re-measure rule.** The briefing's correction phrases return zero over this corpus (`grep -icE "i said"` → 0, `"i told you"` → 0, against `"skill"` → 625 on the same pipeline), while the user corrects with "Hold up.", "Wait,", "Why was…", "Shouldn't we". Replacing the list with the local forms was rejected: a list tuned to one user's August fails the same way one vocabulary later. Both lists stay, the zero is carried as a recorded negative, and the briefing points at `evidence.md`'s known-hit rule rather than restating it — the same placement the enumerator bullet above gives the script case, since a vocabulary that returns zero is a search that returned zero and the covering rule already binds it.

## Amendments

- **2026-08-29 — batch 1 landed.** Seven rules in `scripts/security.sh` — `sh-imds`, `sh-agentcfg`, `sh-persist`, `sh-noverify`, `sh-envdump`, `uni-confusable`, `bin-bytecode` — each with annotated fixture instances under `scripts/lint-fixtures/security/` and a row in `security-selftest.sh`'s mutation table, which holds 45 rows after the review's fix pass the same day (`grep -c '^mutation "' scripts/security-selftest.sh` → 45), each naming the instance it must go red on; the `CLAUDE.md` § Linting mutation rule; the two `DOMAIN.md` rows; and this record. Two judgment calls made in the batch are recorded here because nothing else in the tree says why. **The homoglyph table is hand-listed**, 52 code points in the scanner's `CONFUSABLE` string (`len()` of the literal → 52: the batch's 46, plus the six Greek lowercase forms — alpha, epsilon, rho, tau, upsilon, chi — the review found missing while their capitals were present), rather than vendored from Unicode's `confusables.txt`. The rule flags a lookalike only inside an otherwise-ASCII token, so the table needs only the letters that pass for ASCII ones, and `confusables.txt` maps pairs across every script, most of which never sit beside ASCII; vendoring it would add a second source with its own update cadence to a rule that reads one line of letters. The cost is stated with the choice: a lookalike the 52 lack is not flagged, and nothing grades the table's completeness — though every member it has is graded, since `security-selftest.sh` reads the string out of the source and reds on a member with no fixture instance. **`.json`, `.toml`, `.yaml` and `.yml` are read as script text**, not as data. A hook command in `.claude/settings.json`, a server command in `.mcp.json`, or a `[tool]` command in `pyproject.toml` runs the same as one in a script, so the narrower reading — an allowlist of command-bearing keys per format — would have to enumerate every place a command can sit and would miss the next one. The cost is that a data-only config is scanned by every script rule; the clean fixture carries a benign config in each format so a rule that widens onto ordinary config turns the selftest red.
- **2026-08-29 — the review of batch 1, 106 findings, and its fix pass.** The review (`skills-2026-08-29-batch-1-review.review.md` in the landing zone) found the gate as shipped quieter than the tree it replaced in two places the subset check could not see and louder in two, and the fix pass made these calls, recorded here because the scanner's header states the *what* and nothing else says why. **A homoglyph is decided per run, not per token.** The batch's guard turned the rule off for any token holding an accented letter, so `café.reаd` was silent; a token is now split into runs at `.`, `-`, `_` and at any letter outside the table, and a run mixing ASCII with a lookalike is the hit.
