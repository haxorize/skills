# work-item-shape extracts the work-item quality core into a behavior

The discipline that makes a work item good lived only inside the four `to-*` publishers — quadruplicated where it was shared (`cold-reader-pass.md` sat byte-identical in all four `references/` dirs) and unreachable where it was needed most: a casual "file a story for this" could never surface a publisher while the publishers carried `disable-model-invocation` (they have not since [ADR-0115](0115-the-to-publishers-are-model-invoked.md)), so the model's honest options were a raw `gh`/`az` lookalike outside the pipeline or nothing. The 2026-08-08 mining round (mathews-tom/agent-armory `d9ef25b`, openai/skills `49f948f`) supplied the quality core the suite lacked. We extracted `work-item-shape`, a model-invoked behavior owning what a good body *is*:

- the outcome-not-activity goal test with its greppable reject list and five-element goal,
- acceptance-criteria checkability (three admissible evidence kinds, independent verifiability, implicit negative-path criteria derived from every stated limit, per-work-type done conditions, the most-honest-binary-validator fallback for placeholders),
- the readiness gate that justifies the existing Task `## Mode` AFK/HITL label, five predicates since the 2026-09-04 round's batch 6 ([ADR-0084](0084-batch-family-6-7-admissions-2026-09-04.md)) added the hidden-trunk one (code whose callers the item cannot enumerate, or a global registration no importer names, denies AFK however clear the item), with the three scoping lines an AFK item carries, the stop condition among them, in `references/afk-scoping.md`,
- non-temporal sizing tests with the merge-upward direction,
- the three-type ambiguity block (Unclear/Missing/Conflicting with verbatim quote, question, impact, assumption),
- the Cold-reader pass, which moves here whole, dissolving the four-way sibling group,
- and **Naming drift**, the publish-time check [ADR-0048](0048-naming-drift-queue-trimmed-to-check-only.md) kept when it removed the queue, moved here from the three publishers that carried it so the check has one owner and binds ad-hoc drafting too.

Each publisher declares it via `requires:`; it in turn requires `writing-for-humans`.

Correct creation is routed, in depth. [ADR-0115](0115-the-to-publishers-are-model-invoked.md) made the publishers model-invoked, which replaced this record's one-funnel argument: one trigger-rich `work-item-shape` description that stopped to name a typed `/to-*` command. Layer one is now each publisher's own description, with `work-item-shape`'s routing gate loading the right publisher when the behavior fires first on a tier-named or tierless creation ask in a pipeline repo. Ad-hoc drafting there would skip parent reconciliation, `Covers:` wiring, tags, templates and update modes. Layer two, the deterministic one: repos wired for the pipeline pin the policy in their own `CLAUDE.md` with the routing policy line `onboard-repo` writes, which says work items are created only through the publishers and never with raw `gh`/`az` calls, and that a casual ask loads the right publisher. Layer three, the floor: ad-hoc drafting stays first-class where it belongs (no pipeline, someone else's repo, an explicit overrule), and there the shape rules still bind — the parent question must be answered or explicitly scoped out, so even the fallback can't silently orphan an item.

The contested calls:

- **Naming:** `work-item-shape` keeps the glossary's umbrella term even though "work item" reads as ADO jargon in the wild — `DOMAIN.md` claims it as the tracker-neutral umbrella, and the tier argument decides: the behavior shapes Feature bodies too, and a Feature is not a Ticket by the glossary's own aliases-to-avoid, so `ticket-shape` would be wrong-tier. The wild-world synonyms (ticket, issue, story, bug) do their work in the description, where triggers live.
- **Publication constraints:** one deliberate softening — a stable invocation surface (a script name, CLI command, or endpoint) may now be named in a verification clause; those are contracts, not the internals the drift argument protects, and a checkable criterion needs a nameable check (armory's "unless the file identity itself is the contract" exception, adopted narrowly). Internal field, type, and file names stay banned everywhere. This amends ADR-0014's blanket rule; that record carries the matching pointer.

Rejected: armory's `.out-of-scope/` rejection ledger (covered — ADR rejections are decisions, and chart-course Charts carry out-of-scope rulings); define-goal's ask-a-question branch (the publishers stay synthesis-only and interviewing stays the grill's job — only its repair survives, as the binary-validator fallback); the spec-quality rubric (a negated mirror of the rules, no mechanism); and every time-based sizing figure (the three sources disagree — 1–4 hours, 1–2 days, 1–3 days — which is the tell that hours were never the invariant; the structural tests are).
