# writing-for-humans synthesized from the writing-sources mine

Nothing in the suite governed sentence-level prose for humans — the publishers carry structural rules (plan-not-changelog, Cold-reader pass) and `writing-for-agents` governs instruction files, but no skill said how a ticket body, ADR rationale, summary, or error message should read. The 2026-08-08 mining round produced `writing-for-humans`, a model-invoked behavior synthesized from ten sources (aminblg-simpleenglish's STE catalog, docwriter-org, tbhb-vale-ai-tells, petergyang-no-ai-slop, mathews-tom humanize, tajd's Economist distillation, GOV.UK's research-backed guidance, jakubkrehel better-writing, rhyssullivan error-messages, bholmesdev simplify) plus Orwell's six rules, consumed via `requires:` by the four `to-*` publishers, `adr`, `backfill-adrs`, `chart-course`, `wait-what`, `ship`, `wizard`, `ask-for-me`, `capturing-learnings`, and `teach-me` (scoped to its durable artifacts — the dialogic lesson flow keeps its pedagogic register). The wiring test: skills that author durable human-read artifacts get the dependency; skills whose output is an ephemeral chat report do not (`review-changes`, `verify-docs`, `audit-tests`, `black-box-check`, `improve-design` — the last routes its durable story through `to-story`, and reports are already governed by finding-discipline).

Three shaping decisions. **Boundary by function, not audience:** agents read ADRs too, so "agent-facing vs human-facing" cannot split the two writing skills; the test is *obeyed vs understood* — documents that steer process (skill bodies, CLAUDE.md, references) stay with `writing-for-agents`, prose that transfers understanding (tickets, ADR rationale, DOMAIN.md definitions, summaries) moves here, and `writing-for-agents`' description was amended to match. **Reader-service, never camouflage:** humanize's statistical-mimicry rules (seeded fragments, controlled imperfection, detector-score proxies) were rejected wholesale — our readers know an agent wrote the text, so evasion serves no one and contradicts the tell catalog; distributional rules survive only where uniformity genuinely hurts reading (monotone openers, sustained passive, one-point dilution). **Checkable forms over verbatim Orwell:** each of the six rules ships as its testable descendant (press-release test for stale metaphor, conversational test for word choice, cut-with-a-floor, the "by whom?" passive test with named repairs, scope fences instead of the taste-based escape), with a lineage note instead of an epigraph.

Also rejected, with reasons that generalize: porting Vale's 108-rule linter catalog or its two-agent fix loop (machinery; the curated named-tell catalog with displacement partners carries the value); the STE approved-word dictionaries and the Economist WORDS.md table (copyright-encumbered — the dictionary-membership test and instruction-shaped substitution rows are the shippable forms); docwriter's total metaphor ban as a universal rule (it would outlaw `writing-for-agents`' leading words — the ban is scoped to human-facing prose, where literal labels win); rule *numbers* anywhere in the catalog (aminblg's tested finding: models cite invented numbers — rules are addressed by name).

**Amended 2026-08-08:** a wiring audit found the test above was applied to the orchestrators that *visibly* author artifacts and missed the inline-write paths. `grill-and-record` writes ADRs inline — its deliberate bypass of the `adr` skill carried the write but not that skill's dependency — and `domain-modeling` writes the DOMAIN.md definitions this record itself assigns to writing-for-humans territory; both now `require:` the behavior, invoked lazily at the first write so a grill pays the load only once prose exists (the same fix restores the standalone path's other lost rule: the owning-record check runs before the gate, inline too). `receiving-review` joined the consumers — its per-thread PR replies became durable tracker prose when the reply contract landed, a gap created and closed in the same round. `improve-design`'s unwiring is narrowed rather than reversed: the original ruling weighed the story (routed through `to-story`) and the chat report (finding-discipline) but not the design-sketch comment filed when the user declines an ADR — a durable human-read artifact; the dependency is now scoped to that write. `handoff` stays unwired, now as a recorded ruling instead of an accident of silence: the doc is throwaway by design (OS-tmp default, pointers to the durable artifacts), consumed by one agent session, and already carries its own prose discipline (status-over-orders, reference-don't-duplicate) that a register layer would fight. The `writing-for-agents` side audited clean — only `write-skill` authors durable instruction files, and the CLAUDE.md block appends elsewhere (severity labels, tracker blocks) are structured data, not prose.
