## Context

None of the six commits touched `docs/lineage.md` (`git diff --quiet 685b4e0...b202440 -- docs/lineage.md` → exit 0), so by that file's own header sentence every one of those files read as a local original, and `CLAUDE.md` makes that file the mandatory read before any skill is materially edited.

The family-4 review of this date (`skills-2026-09-04-batch-family-4a-4f.review.md`, F15) named the gap and two aggravators: one source is Apache-2.0 and landed as adapted wording with no attribution anywhere in the repository, and four sources are ideas-only, whose rows the round's own `briefing.md:34` requires to say so in their own text — none did. [ADR-0081](0081-batch-2-scanner-admissions-2026-09-04.md) had already rejected the deferral this repeats, in as many words: "the closing ADR's date is not fixed, `docs/lineage.md` is read on every scanner edit, and a `Record` cell that names an unwritten record is a deferral with no owner." This record is that lesson applied to the batch family that was landing while it was written.

## Considered Options

- **Leave the record to the round's closing ADR**, the plan's shape. Rejected for ADR-0081's reasons, now demonstrated twice in one day: the closing ADR's date is still not fixed, six commits landed against an unwritten record, and one Apache-2.0 adaptation sat without attribution for the interval.
- **One record per batch**, the shape ADR-0081 took for batch 2. Rejected: batch 2 stood alone because it was the scanner's. Here three upstreams span batches — addyosmani across 4b and 4e, wshobson and rampstackco across 4b and 4f — and six records would name each of them twice, with two `Record` cells for one lineage row. The unit that matches the lineage table is the source, and the family is the smallest unit that holds every source once.
- **Row the two new references in the first table**, as ported directories to diff before editing. Rejected: neither has a directory to diff — each is a synthesis in local prose from three to four upstreams, the shape `writing-for-humans` holds in the second table — and a first-table row would send an editor to diff four repos for a paragraph none of them contains.
- **An attribution block inside `agent-driven-cli.md` and `ship/SKILL.md`** for the two Apache-2.0 sources. Rejected: neither upstream has a `NOTICE` file, so §4(d) asks for nothing to be reproduced; a skill body naming a repo record is what `lint-skills.sh` fails, and `CLAUDE.md` sends a reader to `docs/lineage.md` for lineage — the attribution lives where every other upstream's does.
