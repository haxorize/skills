# Retired form with arguments

A publisher's arguments ride the same slash form: `/fixture-discipline --parent {ID}` names
the model-invoked skill as plainly as the bare form does, so the check must read the name
before the space and fire here too. This file carries no bare form, so the args-form row
is graded by this line alone.

The quiet neighbor: `/no-such-dir/notes.md` is a path in the slash form, not a command,
and must stay silent. A pattern that drops the required space reads `no-such-dir` as a
dangling command name.
