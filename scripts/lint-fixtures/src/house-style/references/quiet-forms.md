# The quiet forms

Every line here is a form a house-style check must leave alone. A FAIL naming this file
is a check that widened, which is half of what the selftest grades — the other half is
the firing instance in the body that points here.

## The quiet half

- A suggestion naming a model-invoked skill stays bare: run `fixture-discipline` first.
- A repo-convention filename is exempt from the artifact-name shape: `README.md`.
- A registered label is not a coinage: the row reads **FIXTUREPASS** and closes.
- A British form inside a code span is a literal, not prose: an order in `cancelled`
  never leaves that state.
- A British form inside a URL is somebody else's path, not this repo's prose:
  https://example.invalid/docs/behaviour is left alone.
- A pointer that resolves names a heading its target carries:
  [the sibling note](sibling-note.md) § The sibling half is where it lands.
