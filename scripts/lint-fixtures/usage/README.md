# Usage fixture

`scripts/skill-usage-selftest.sh` points `scripts/skill-usage.sh` at this directory. `history.jsonl` is the typed side; `projects/` the loaded side. Every line exists to be counted or to be left alone. Counted: the bare `/tdd`, the `/tdd` with arguments, `/grilling` twice (one in July, one on 2026-08-01 — the day a `--since 2026-08-01` window must keep), the bare `/committing`, the `Skill` tool_use blocks in `sess-1`, `sess-2-truncated`, `sess-4` and the subagent transcript `sess-3-subagent`. Left alone: `/tdd-extra` (a prefix, not the name), `/clear` (off the roster), the prose `please run /committing for me` (a typed invocation starts with the slash), the `Launching skill:` text, the `StructuredOutput` block carrying `"skill":"tdd"`, and the user turn typed inside a transcript. `sess-2-truncated.jsonl` ends mid-line on purpose — it is what marks every loaded count as a floor; the typed-side floor is exercised on a truncated copy of `history.jsonl` the selftest makes in a temp directory.
