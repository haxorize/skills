# Fixture glossary (clean)

The quiet half of the slash sweep's `DOMAIN.md` arm: `/which-skill` names a
user-invoked skill and `/simplify` is a built-in with no skill body, so neither may
fire.

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Cold-reader pass** | A registered term, so its capitals may open a clause mid-heading and the heading-case check stays quiet on them | Fresh-eyes read |
| **Status marker** | The registered label family: `FIXTUREPASS` and `FIXTUREFAIL`. A body writing either draws nothing; a body coining a third draws a FAIL, so removing a name here is what the selftest does to prove the check reads this file | Flag |
