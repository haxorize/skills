# Clean fixture root

A miniature repo root that is **right** on purpose — the mirror of `scripts/lint-fixtures/`, which is wrong on purpose. `lint-skills.sh` exits 0 against this tree, and that is the whole point: it gives `lint-skills-selftest.sh` a root where an induced failure is attributable to the thing induced. The wrong-on-purpose tree cannot do that, because its deliberate violations already force exit 1 there — `lint-skills-selftest.sh` pins how many, so the count lives in one place rather than in prose that drifts.

Keep it clean. A violation added here turns the read-error assertion in `lint-skills-selftest.sh` back into the vacuous check it was written to replace.

## Skill map

- **`clean-skill`** — the one model-invoked skill, carrying a reference file the link extractor must read, and three resolving `§` pointers into it: one on the plain name, one on a numbered heading cited without its number, and one whose name carries a comma and resolves only through the section-pointer check's comma cut, against the `Sizes and shapes` heading in that note; its description quotes one phrase twice, which the shared-trigger-phrase check must not read as a duplicate.
- **`near-cap`** — a body just under the 15,000-byte re-attach bound, which must draw no FAIL and no WARN; a threshold that drifts low reds here. Its description and `clean-skill`'s share one backticked span, which the shared-trigger-phrase check compares nothing against — widening that check past double-quoted spans turns this root red.
- **`which-skill`** — the router, present because the router-coverage check requires one; user-invoked, and quoting `clean-skill`'s phrase to prove the shared-phrase check never reads a user-invoked description.
- **`ledger-legend`** — the quiet half of the three evaluation-ledger checks (`check_evaluation_ledger_authority`, `check_evaluation_ledger_rule_agreement`, `check_evaluation_ledger_consumers`), and the only skill here whose fixtures span three files: `references/legend-line.md` carries the legend, the stored-status rule in its `SKILL.md` defines the same three members, and `references/complete-consumer.md` enumerates all three. All three rows of that check therefore stay quiet, and `complete-consumer.md` is the file `lint-skills-selftest.sh` breaks in an isolated copy of this root to prove the check moves the exit status on its own.

`global/rules/clean-rule.md` is the one global rule, cited by `clean-skill` so the `Depends:` check stays quiet. `global/hooks/paired-hook.sh` (with its `# Install note:`) and its executable `paired-hook-selftest.sh` are the hook-selftest check's quiet form; `scripts/paired-tool.sh` and its executable `paired-tool-selftest.sh` are the script-selftest check's. `adr/` is `scripts/lint-adrs-selftest.sh`'s clean fixture — five records: a link-form pair, a supersession pair that links both ways, and a bold-form pair with its pointer; the link-form target also carries a `— corrected:` Consequences line and a `— settled:` Deferred line, both pointing at the dated amendment below them, and cites a third record in plain prose, so the corrected-marker and cross-reference checks each have a quiet form here too.

Three files sit outside the skill map, each the quiet half of one arm of the pass-2 classifier: `src/stray-note.md` is a markdown file at depth one under `src/` with no owning `SKILL.md`, `DOMAIN.md` is the glossary class, and `.claude/skills/repo-local/SKILL.md` is the repo-local class the slash sweep reaches but pass 1 and pass 4 do not. Each names a user-invoked skill or a built-in in the slash form, and none may fire; their firing halves live in `scripts/lint-fixtures/`.
