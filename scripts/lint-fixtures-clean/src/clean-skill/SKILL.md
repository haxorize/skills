# Clean Skill

Do the thing the check needs, then read [references/note.md](references/note.md) for the note it leans on.

This skill leans on `clean-rule` for the admission check's citation direction.

## The Cold-reader pass

A term registered in this tree's `DOMAIN.md` opens a clause mid-heading, and the
heading-case check reads the glossary rather than chasing the capital.

## Phase 2 — Reproduce the thing

A numbered label and an acronym are the other two capitals that are not violations, so
this heading and the `HTML` one below stay quiet.

## The HTML half

- A registered label draws nothing: the row lands **FIXTUREPASS** and closes.
- A repo-convention filename is exempt from the artifact-name shape: `README.md`.
- A British form inside a code span is a literal: an order in `cancelled` stays there.
- A model-invoked skill at a suggestion site stays bare: run `clean-skill` again.
- A pointer that resolves names a heading its target carries:
  [the note](references/note.md) § Note is where it lands.
- A numbered heading is cited without its number:
  [the note](references/note.md) § The numbered half is where a step lands.
- A citation whose name carries a comma resolves through the comma cut alone:
  [the note](references/note.md) § Sizes, and what they bind is where it lands.
