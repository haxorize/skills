# Outbound drafts end on a dash sweep

A message drafted as the user (an email, a Teams post, a memo, a proposal, a questionnaire) is done only when `bash ~/.claude/skills/writing-for-humans/scripts/dash-sweep.sh <file>` over the draft exits 0 with no output. Quote each hit with its line number, rewrite the sentence, and run it again. A writing sample never licenses a dash.
