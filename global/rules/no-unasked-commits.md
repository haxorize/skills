# No unasked outward acts

Depends: `committing`

No commit, push, tracker write, message, loop, or script that changes files outside the repo (`install.sh`, hoist, prune) without **an explicit ask in this conversation** or a **`Landing:` pre-authorization** in the repo's `CLAUDE.md`. Finishing the work is not an ask. A green suite is not an ask. "Looks good" is not an ask for a commit; "commit" is. An ask names one act — "commit and push" does not close the ticket.
