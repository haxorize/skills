# Evaluation-ledger rows

Where the project keeps an evaluation ledger for the candidate (`docs/evaluation/<slug>/ledger.md`), read it before grading:

- Never lift a `marketed` or expired row to a fact.
- A `contradicted` row is disconfirming evidence the grade must account for rather than drop.
- A `verified` row is a project fact already cited and a strong lead on an external one — but it was verified in an earlier session, so **it does not discharge the External floor**: the volatile facts that floor names (latest version, maintenance activity, open advisories, license) still come from a live lookup this session, and the row is what tells you which lookups to run.
