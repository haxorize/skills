# The chat fallback

Open this only when a script is the wrong medium for the setup and the steps will be walked in chat instead.

Run the same discipline in chat: still steps the human *performs*, which is what separates this from `ask-for-me`, a questionnaire for knowledge they hold.

Keep the canonical checklist internally, complete and uncapped. Present **one atomic human step per message** with its full detail; after each completed step, show the remaining items as a headline-only list — a few glanceable words each, no commands, URLs, or values (detail appears only when an item becomes the current step). Before every reply, re-audit the visible list against the internal checklist, and cap the visible list at 8 items by merging far-off steps into phase-level headlines.
