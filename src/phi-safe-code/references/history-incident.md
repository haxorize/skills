# A PHI value in published history

Open this only when a PHI value is found already committed to shared history, or a commit about to be pushed is discovered to carry one. The body's rule stands: this is an incident, not a typo — raise it through the project's incident path before any edit to history, and never run your own amend, tip-edit, or force-push.

The incident path preserves the evidence first — the original refs bundled or tagged, the SHAs recorded on the ticket — and then decides the purge, the clone sweep, and the host's cache. Your own amend, tip-edit, or force-push is not a remediation: it forfeits the record the response needs, leaves every existing clone holding the original, and settles nothing, because whether this is a reportable breach is the assessor's call, never an engineer's output from a repo.
