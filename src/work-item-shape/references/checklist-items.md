# Checklist items in a self-review

Open this when the Cold-reader pass, or any self-review, works from checklist items.

The items test the English, not the future code: each interrogates the requirements text itself — "is 'prominent display' quantified with a size or position?" — and tags what it probes (a gap, an ambiguity, a conflict, an assumption, or the section it checks). An item that starts "Verify/Test/Confirm" plus implementation behavior fails that test.
